CommunityPal Issue Tracker

Welcome to the official issue tracker for CommunityPal, a web app designed to help communities connect, collaborate, and grow. Use this repository to report bugs, request features, or suggest improvements.

Before submitting an issue, please check existing reports to avoid duplicates. When reporting, provide as much detail as possible, including steps to reproduce, screenshots, and browser information.
